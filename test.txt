MODULE A — VEHICLE MAINTENANCE SCHEDULER
================================================================
Controller : VehicleMaintenanceController
Service    : VehicleMaintenanceService
Algorithm  : 0/1 Knapsack — Dynamic Programming
             Time O(depots × N × W), Space O(N × W)

----------------------------------------------------------------
[A-1] RUN VEHICLE MAINTENANCE SCHEDULE
----------------------------------------------------------------
METHOD  : GET
URL     : http://localhost:8080/api/vehicle-maintenance/schedule
HEADERS : (none required — no auth on local routes)
BODY    : none

CURL:
curl -X GET http://localhost:8080/api/vehicle-maintenance/schedule

WHAT HAPPENS:
1. App calls EXT-2 (Depots API) — gets 5 depots
2. App calls EXT-3 (Vehicles API) — gets 28 vehicles
3. Runs 0/1 Knapsack DP for each depot
4. Prints detailed schedule table to server console
5. Returns JSON summary

RESPONSE (200 OK):
{
  "status":  "success",
  "message": "Schedule computed for all depots. See server logs for results."
}

RESPONSE (500 — if Affordmed API unreachable):
{
  "status":  "error",
  "message": "<exception message>"
}

SERVER CONSOLE OUTPUT (example):
╔══════════════════════════════════════════════════════════╗
║  Depot #1 │ Budget: 60 hrs │ Max Impact: 312
║  Hours Used: 59 / 60 │ Tasks Selected: 18

║  0bf780cb-1099-4f61-99bf-dec95a7063b6  Duration=3   Impact=10
║  8a7ff5b1-335c-4a2f-96d8-09c4a362e781  Duration=6   Impact=10
╚══════════════════════════════════════════════════════════╝

LOGS SENT TO AFFORDMED:

[B-4] GET PRIORITY INBOX (Stage 6 — Top-N)
----------------------------------------------------------------
METHOD  : GET
URL     : http://localhost:8080/api/notifications/priority
PARAMS  : topN (optional, default=10)
HEADERS : (none)
BODY    : none

CURL (top 10 — default):
curl -X GET "http://localhost:8080/api/notifications/priority"

CURL (top 15):
curl -X GET "http://localhost:8080/api/notifications/priority?topN=15"

CURL (top 5):
curl -X GET "http://localhost:8080/api/notifications/priority?topN=5"

ALGORITHM: priority = typeWeight × e^(−0.05 × ageInHours)
typeWeight: Placement=3.0, Result=2.0, Event=1.0

Examples:
New Placement  (age=0h)  → 3.0 × 1.000 = 3.000
New Result     (age=0h)  → 2.0 × 1.000 = 2.000
New Event      (age=0h)  → 1.0 × 1.000 = 1.000
24h Placement            → 3.0 × 0.301 = 0.903
24h Result               → 2.0 × 0.301 = 0.602
